계정 삭제 안내

Lighter 계정 삭제하기

계정은 앱에서 언제든 직접 삭제할 수 있어요. 삭제하면 아래 정보가 지워지고 되돌릴 수 없어요.

앱에서 삭제하기

  1. Lighter 앱을 열고 하단 프로필 탭으로 이동해요로그인되어 있어야 해요.
  2. 계정 · 지원 → 회원 탈퇴를 눌러요삭제되는 항목과 안내가 표시돼요.
  3. 닉네임을 입력하고 ‘탈퇴하고 계정 삭제’를 눌러요확인을 위해 내 닉네임을 정확히 입력해야 버튼이 켜져요. 누르는 즉시 계정 삭제가 진행돼요.

프로 멤버십을 구독 중이라면 앱에서 탈퇴해도 결제가 멈추지 않아요. iPhone 설정 → 내 이름(Apple ID) → 구독 → Lighter → 구독 취소에서 따로 해지해주세요.

앱을 쓸 수 없을 때 — 이메일로 요청하기

앱을 지웠거나 로그인할 수 없다면 가입한 이메일 주소로 아래 내용을 보내주세요. 본인 확인 후 계정을 삭제하고 결과를 메일로 알려드려요. 요청을 받은 날부터 10일 이내에 처리해요.

  • 받는 곳: help@lighter.run
  • 제목: [Lighter] 계정 삭제 요청
  • 내용: 가입 이메일, 닉네임

계정 삭제 요청 메일 쓰기

삭제되는 정보

탈퇴하면 다음 정보가 지체 없이 파기돼요(정당한 사유가 없으면 5일 이내). 복구할 수 없어요.

  • 계정 정보 — 이메일, 비밀번호, 닉네임, 성별, 소속, 프로필 사진
  • 본인인증 결과 — 성인 여부, 연계정보(CI)·중복가입확인정보(DI)
  • 러닝 기록과 통계 전체 — 이동 경로 포함
  • 번개 매칭 내역
  • 친구 목록과 대화 내용
  • 저장된 안전 연락처
  • 신체·건강 정보와 외부 서비스(Apple 건강 등) 연동 정보
  • 알림·공개 범위 등 설정값

이미 다른 회원에게 공유된 기록처럼 기술적으로 분리할 수 없는 정보는 예외일 수 있어요(이용약관 제13조). 탈퇴 전에 기록을 보관하고 싶다면 프로필 → 계정 · 지원 → 내 데이터 내려받기로 먼저 받아두세요.
